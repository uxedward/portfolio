# Edward — Product Design

Personal portfolio for [Edward Sudjono](https://www.uxedward.com) (`@ux.edward`): product designer at tiket.com and design educator.

Rebuilt in Next.js for Vercel, migrating the live Framer case studies into an editorial work index.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- MDX case studies in `content/work`

## Local

```bash
npm install
npm run dev
```

## Deploy

Connect this GitHub repo to a new Vercel project. After the preview looks right, attach `uxedward.com`.

Old Framer URLs redirect:

- `/case-1-tiket-carrental-redesign` → `/work/car-rentals`
- `/case-2-tiket-bus-error` → `/work/bus-search`
- `/case-3-tiket-train-bookingform` → `/work/train-booking`
